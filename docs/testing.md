# Тестирование проекта matrix_row_swap

Лабораторная работа № 4, уровни 1 и 2, вариант 13. Проверяется проект перестановки строк вещественной матрицы из ЛР № 3. Метод варианта — анализ причинно-следственных связей. Целевое покрытие — не менее 75 %.

## План

1. Запустить исходные тесты и измерить покрытие.
2. Добавить проверки ввода и обработки матрицы по методу варианта.
3. Проверить вывод, управляющий модуль, HTTP-клиент и сервер.
4. Применить методы «белого ящика» к отдельным решениям.
5. Повторно проверить локальное и сетевое взаимодействие модулей.
6. Зафиксировать дефект, исправление, покрытие и результаты инспекции.

Среда: Windows, Python 3.11.6, pytest 9.2.0, pytest-cov 7.1.0.

## Методы «белого ящика»

Покрытие решений проверено на сравнении индексов строк экстремумов в модуле вывода. Для равных индексов выводится сообщение о сохранении матрицы, для разных — о перестановке. В обоих случаях проверяется текст сообщения.

Покрытие условий и их комбинаций проверено для решения `not isinstance(matrix, list) or not matrix`. Условие A означает, что вход не является списком. Условие B означает, что вход имеет ложное логическое значение.

| Вход | A | B | Ожидаемый и фактический результат |
|---|---|---|---|
| `None` | Истина | Истина | Матрица отклонена |
| `5` | Истина | Ложь | Матрица отклонена |
| `[]` | Ложь | Истина | Матрица отклонена |
| `[[3.5, 4.0], [-2.5, 1.0], [8.0, 2.0]]` | Ложь | Ложь | Матрица обработана |

При истинном A Python пропускает вычисление B. В таблице указаны логические значения, соответствующие входным данным. Фактическое вычисление B с исходами «истина» и «ложь» происходит при ложном A.

## Интеграционное тестирование

```bash
python -m pytest -q tests/test_api.py tests/test_integration.py
```

| Сценарий | Ожидаемый и фактический результат |
|---|---|
| Локальный ввод → обработка → вывод | Нужные строки переставлены и показаны |
| Неверный ввод → повторный ввод → обработка | После исправления ввода программа выдала результат |
| Ввод → HTTP-клиент → сервер → обработка → вывод | Локальный сервер принял JSON, клиент получил результат, программа показала переставленные строки |
| Ошибки HTTP | Некорректный JSON и отсутствующее поле дают 400, неверный формат даёт 415, некорректная матрица даёт 422 |
| Недоступный сервер | Клиент сообщил об ошибке подключения |

В двух выбранных файлах пройдено 17 тестов и 10 подтестов. В них есть сквозные сценарии и дополнительные проверки обработки матрицы. Сервер в сетевых сценариях запускается на локальном адресе со свободным портом.
