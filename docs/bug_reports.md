# Баг-репорты

## BR-01 Округление вещественных чисел при выводе

**Среда:** Windows, Python 3.11.6. Исходная версия для воспроизведения — коммит `558636e`.

**Описание:** близкие вещественные числа отображаются одинаково в матрице, минимуме и максимуме.

**Шаги воспроизведения:** запустить `python src/main.py` из корня проекта, ввести 2 строки, 1 столбец, затем значения `1.0000001` и `1.0000002`. Эквивалентная команда в Git Bash:

```bash
printf '2\n1\n1.0000001\n1.0000002\n' | python src/main.py
```

**Ожидаемый результат:** в первой строке `1.0000002`, во второй `1.0000001`. Минимум — `1.0000001`, максимум — `1.0000002`.

**Фактический результат:** в обеих строках, в минимуме и в максимуме напечатано `1`. Проверка `test_prints_distinct_decimal_values` завершилась ошибкой `AssertionError`.

**Серьёзность:** средняя. **Приоритет:** средний. **Статус:** исправлено.

**Причина:** формат `:g` по умолчанию выводит до шести значащих цифр.

**Исправление:** значения преобразуются через `str()`. Для чисел с окончанием `.0` оно убирается при выводе.

**Повторная проверка:** оба числа, минимум и максимум выведены с ожидаемой точностью. Набор из 26 тестов сразу после исправления прошёл полностью. В завершённом наборе пройдены 37 тестов и 10 подтестов.
