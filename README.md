# Обработка вещественной матрицы

Программа предназначена для обработки вещественной матрицы размерности n × m.

В соответствии с вариантом программа находит максимальный и минимальный элементы матрицы и меняет местами строки, в которых расположены эти элементы.

## Требования к окружению

- Python 3.x
- Сторонние библиотеки не требуются

## Запуск программы

Запуск программы выполняется из корневого каталога проекта командой:

```bash 
python src/main.py
```

## Стратегия ветвления

В проекте используется упрощённая стратегия Git Flow.

Ветка `main` содержит стабильную версию проекта.

Ветка `develop` используется для внесения и проверки изменений перед их слиянием в `main`.

Изменения сначала выполняются в ветке `develop`, после проверки фиксируются коммитом и затем сливаются в основную ветку `main`.
